3 git branch -M main Renamed master branch to main Sets current active working branch pointer to modern industry standard main.

5 git commit -m "<msg>" Recorded project snapshots with descriptive messages Creates a permanent SHA-1 snapshot with commit metadata in local repository history.

7 git checkout main Switched back to primary branch main Updates HEAD pointer and working tree to point to the latest commit on main.

Question 2 Solution: Test Case Design for Login System

10 Marks

Application Under Test: Login System with Username, Password, and Login Button.

Functional Requirements Specification

  • Username must not be empty.
  • Password must be at least 6 characters long.
  • Valid credentials allow successful login.
  • Invalid credentials display a specific error message.
  • Account locked after 3 consecutive failed login attempts (15-minute lock cooldown).
